# Build log

## M0 — Setup & data spike (2026-10-20)
- **Built:** Vite 8 + React 18 + R3F 8 + Tailwind 4 + TS 5.9 scaffold; `npm run data` pipeline (fetch FX/macro/Big Mac/BIS → build → validate) writing 6 JSON snapshots for all 12 places; blank golden-hour canvas with fonts; refresh-data GitHub Action.
- **Expected:** All §5 endpoints to work as written.
- **Actually:** Frankfurter moved to `api.frankfurter.dev/v1` (`.app` 301s). World Bank `PA.NUS.PPPC.RF` is archived (source 57, stale) → derived as `PA.NUS.PRVT.PP ÷ PA.NUS.FCRF` (household-consumption PPP; within ~0–10% of the archived GDP-based ratio, Switzerland archived value looks like a 1.000 placeholder). `FR.INR.RINR` has no France/Türkiye data and stops 2014 (UK), 2017 (Japan) → added BIS policy rates via API and a derived "policy rate − CPI inflation" real rate. Big Mac has no France row → euro-area (EUZ). BRL/INR ECB data starts 2000. No month-over-month FX move exceeds 40% (largest: TRY Dec 2021 +25.9%).

## M1 — Look & feel (2026-10-20)
- **Built:** Golden-hour lighting rig (soft 2048 shadows, hemisphere fill), camera-relative gradient sky, exp fog, dust particles, slow camera drift (both off under reduced motion); blocky Character (4 hair styles; idle/wave/walk/huddle); Paris diorama (block Eiffel Tower, Seine + Pont d'Iéna, Haussmann blocks, Champ de Mars, café, lamps, pedestrians, a walker crossing the bridge); serif Caption with 40ms word-group stagger, count-up HUD number, frosted tab bar; live ECB rates with snapshot fallback; pure `crossRate`/`convert` + tests (20 total).
- **Expected:** Draw calls would be the bottleneck with hundreds of boxes.
- **Actually:** A `Builder` that batches static parts by (geometry, color) into instanced meshes keeps Paris at 116 draw calls *including the shadow pass* and ~9.6k triangles, 120 fps on an M-series Mac (still need a 2020 MacBook Air check). Characters are now the main draw-call cost → instance crowds if we add more. Sky gradient first used world-origin directions and looked all-gold from the raised camera; fixed by measuring from the camera. White HUD text over the cream band of the sky needs a real contrast check (added a tight second text-shadow).

## M2 — Globe, navigation, onboarding (2026-10-23)
- **Built:** Title → make traveler (turntable) → home country (12 cards, blocky SVG icons) → amount (chips) → globe fly-in → marker card → camera dive + fade → Paris → "← Globe". Low-poly globe (8,820 flat faces) colored from a 1° Natural Earth land mask baked by `scripts/build-land-mask.ts`; 12 markers (mini Eiffel for Paris) tinted by **inflation-adjusted** strength vs 10-year average (`src/finance/strength.ts`, tested); traveler stands on the home city; HTML "Cities" list as the accessible alternative; profile saved to localStorage (validated on load). 36 tests.
- **Expected:** Nominal "today vs 10-year average" would be enough for the marker tint.
- **Actually:** Nominal is badly misleading for high-inflation currencies — for a USD traveler the lira is "+173% stronger than average" nominally but **−10%** after inflation; the yen is +31% real. Switched to the real exchange rate (rate × home CPI ÷ destination CPI; annual WB inflation interpolated monthly; 2025/2026 USD inflation carried forward from the latest year — flag in the Data panel). Other fixes from testing: card covered its own marker (hover flicker) → card lifted above marker; sky looked all-gold from the orbiting camera → screen-space sky gradient for the globe; creator camera FOV leaked into the globe → globe resets its lens. Globe: 62 draw calls, 12.3k triangles, 120 fps (M-series).
